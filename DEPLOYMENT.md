# Инструкция по развертыванию волонтерского бота MAX

### 1. Настройка переменных окружения
Скопируйте шаблон конфигурации в файл `.env`:
```bash
cp .env.example .env
```

Откройте `.env` и укажите:
- `BOT_TOKEN` — токен вашего бота в мессенджере MAX, выданный организаторами.
- `ADMIN_USER_IDS` — ID учетных записей суперадминистраторов в MAX через запятую (например, `12345678,87654321`). Узнать свой ID можно командой `/get_id` в диалоге с ботом.

### 2. Проверка информации о боте (опционально)
Чтобы узнать имя и ID бота перед запуском:
```bash
python3 check_bot_info.py
```

### 3. Запуск через Docker Compose
Соберите образ и запустите контейнер в фоновом режиме:
```bash
docker compose up --build -d
```

### 4. Управление и логи
- Просмотр логов работы:
  ```bash
  docker compose logs -f
  ```
- Остановка бота:
  ```bash
  docker compose down
  ```
